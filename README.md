# 便便日记 poopooDiary

一个纯前端的个人便便记录小工具。数据完全保存在你自己的浏览器里，不上传到任何云端，支持导出 / 导入 JSON 备份，方便换设备时搬家数据。

## 功能

- 自动读取日期，默认显示今天，可前后翻看历史日期
- 记录每日排便状态：时间、布里斯托分类、颜色、量、伴随不适、备注
- 数据只存在浏览器本地（localStorage），无需注册、无服务器
- 一键导出 JSON 备份 / 导入 JSON 恢复或合并
- 手机、电脑浏览器均可使用，响应式布局

## 布里斯托大便分类

| 类型 | 形态 |
| --- | --- |
| 1 | 一颗颗硬球（很难排出） |
| 2 | 香肠状，但表面凹凸 |
| 3 | 香肠状，表面有裂痕 |
| 4 | 香肠或蛇状，光滑柔软（理想） |
| 5 | 断边光滑的柔软块状 |
| 6 | 粗边蓬松块，糊状 |
| 7 | 水状，无固体块 |

## 本地运行

这个项目没有构建步骤，直接双击 `index.html` 即可打开。

也可以起一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 部署到 GitHub Pages

在 GitHub 仓库的 **Settings → Pages** 里，把 Source 选为分支的根目录（例如 `main` 分支的 `/ (root)`），保存后即可通过 `https://<用户名>.github.io/poopooDiary/` 访问。

## 数据说明

- 数据存在浏览器 `localStorage` 的 `poopooDiary.records.v1` 键里
- 清理浏览器缓存 / 数据会导致记录丢失，请定期使用「导出」功能备份
- 「导入」支持两种方式：**合并**（按记录 id 去重合并）和 **替换**（用备份覆盖当前数据）
